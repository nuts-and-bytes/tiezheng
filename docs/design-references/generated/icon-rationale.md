# 部位徽记重绘说明

共同规则：24×24 几何、实心为主、单一轮廓锚点、最多两块负空间；12px 时先保轮廓，再保内部信息。所有徽记使用 `currentColor`，页面负责部位色和选中态。

| 部位 | 识别锚点 | 12px 取舍 | 避免混淆 |
| --- | --- | --- | --- |
| 胸 | 左右对称胸甲与中缝 | 下沿弱化为一条厚切面 | 不画蝴蝶或双圆 |
| 肩 | 两枚向外的三角肌护片 | 只保双肩间距 | 不用圆球加斜柄，避免像放大镜 |
| 背 | 宽肩收腰的双翼 | 保留中央倒三角 | 不用普通盾牌轮廓 |
| 腿 | 两条分离、带膝转折的支柱 | 去掉脚与髋部细节 | 不加横梁，避免像 π |
| 手臂 | 屈臂外轮廓 | 只留肘部与拳峰 | 不再用通用哑铃代替身体部位 |
| 核心 | 收腰躯干与两段腹沟 | 腹沟压缩成两块负空间 | 不画六格细线，避免缩小后糊成网格 |
| 有氧 | 实心心脏与闪电切口 | 心形优先，闪电作为第二锚点 | 不用单独心电折线，避免与数据趋势混淆 |

生成参考中的八角外框没有进入每一枚运行时徽记：小尺寸重复边框会吃掉主体面积。切角语法保留在实心外轮廓、品牌钢印和按钮表面中。
